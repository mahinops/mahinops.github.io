Bit Manipulation

প্রতিটি সংখ্যা হলো on/off switch-এর একটি সারি। Bit trick গুলো সরাসরি সেই switch গুলো উল্টে দেয়।

মূল ধারণা (light switch-এর সারি)

Computer-এর ভেতরে সংখ্যা binary-তে store হয়: switch-এর একটি সারি, প্রতিটি হয় 0 (off) নয়তো 1 (on)। প্রতিটি switch-এর একটি place value আছে: ডান দিক থেকে 1, 2, 4, 8, 16, 32, 64, 128। যে switch গুলো on, তাদের মান যোগ করুন। যেমন 00001100 হলো 8 + 4 = 12। এই page-এ 8টি switch ব্যবহার হয়েছে (Go-র uint8, সংখ্যা 0 থেকে 255)।

  • AND (&): কোনো column 1 হয় শুধু যদি দুই সংখ্যাতেই সেখানে 1 থাকে। Bit check করতে বা রেখে দিতে চমৎকার।
  • OR (|): যেকোনো একটিতে 1 থাকলে 1। Bit on করতে চমৎকার।
  • XOR (^): bit দুটি আলাদা হলে 1। একই মান দিয়ে দুইবার করলে আগের অবস্থায় ফিরে যায়, তাই সমান সংখ্যা কাটাকাটি হয়ে 0 হয়।
  • Shift (<< / >>): সব switch বাঁয়ে বা ডানে সরিয়ে দেয়। 1 ঘর বাঁয়ে সরালে সংখ্যা দ্বিগুণ হয়; 1 ঘর ডানে সরালে অর্ধেক।

Run করে দেখুন

নিজে চেষ্টা করুন

  • একই জোড়ায় (12 আর 10) AND, OR আর XOR করুন। তিনটি result row column ধরে ধরে তুলনা করুন।
  • 1-কে 7 ঘর বাঁয়ে shift করুন, তারপর 3-কে 7 ঘর বাঁয়ে। বাঁ দিকের কিনারা দিয়ে যে bit পড়ে যায় তার কী হয়?
  • 8, 12, 255-এ n & (n-1) করুন। 2-এর power (যেমন 8) কেন 0 হয়ে যায়?
  • 255 আর 128-এর 1 bit গুনুন। প্রতিটির জন্য loop কয়বার ঘোরে?
  • Single number: list-এর order বদলান। উত্তর কি বদলায়? না বদলালে কেন?

সাধারণ ভুল

  • & আর && গুলিয়ে ফেলা। & সংখ্যার bit-এর উপর কাজ করে; && কাজ করে true/false মানের উপর।
  • Operator precedence। Go-তে &, ==-এর চেয়ে বেশি শক্তভাবে bind করে, তাই a & b == 0 মানে (a & b) == 0। C আর কিছু ভাষায় এটা উল্টো, তাই সন্দেহ থাকলে parentheses দিন।
  • Shift করার সময় overflow। Type-এর width পার হয়ে যাওয়া bit হারিয়ে যায়। uint8 1 << 8 ধরে রাখতে পারে না।
  • Signed shift। Negative int-কে ডানে shift করলে sign bit থেকে যায়; বিষয়টা সহজ রাখতে এই page-এ unsigned সংখ্যা ব্যবহার করা হয়েছে।
Complexity, সহজ ভাষায়: AND, OR, XOR আর shift প্রতিটি একটি করে machine instruction (O(1))। n & (n-1) দিয়ে bit গোনা loop-এ ঘোরে প্রতিটি 1 bit-এর জন্য একবার, প্রতিটি bit position-এর জন্য নয়। Single-number trick list একবার scan করে এবং বাড়তি memory লাগে না।
