Stack: Valid Parentheses

Stack মনে রাখে কোন bracket এখনো খোলা আছে, আর সবশেষে খোলা bracket-টাকেই আগে বন্ধ করতে হয়।

মূল ধারণা

Stack অনেকটা একটার উপর আরেকটা রাখা প্লেট-এর মতো: নতুন প্লেট শুধু উপরে রাখা যায়, আর নেওয়াও যায় শুধু উপর থেকে (last in, first out)। Bracket check করতে text-এর উপর দিয়ে এক এক করে যান। প্রতিটা opening bracket stack-এ push করুন। প্রতিটা closing bracket-কে উপরের প্লেটের সাথে মিলতে হবে, মিললে সেই প্লেট সরিয়ে ফেলুন। না মিললে (বা stack খালি থাকলে) text invalid। শেষে stack অবশ্যই খালি থাকতে হবে।

Run করে দেখুন

নিজে চেষ্টা করুন

  • {[()]} run করুন, তারপর {[(])}। দ্বিতীয়টা ঠিক কোথায় fail করে?
  • ((( দিন। প্রতিটা অক্ষর ঠিক আছে, তবু এটা invalid কেন? শেষে stack-টা দেখুন।
  • শুধু ) দিন। উপরের element দেখার আগে code কী check করে?
  • ()[]{}-এর মতো পাশাপাশি জোড়া দিন। Stack সবচেয়ে বেশি কতটা উঁচু হয়?

সাধারণ ভুল

  • উপরের element পড়ার আগে stack খালি কিনা check না করা: Go-তে এতে crash হয় (index out of range)।
  • বাকি থাকা element check না করে true return করা: ((( loop-এর ভেতরে কখনো fail করে না। শেষের len(stack) == 0 check-টা তাই জরুরি।
  • Stack-এর বদলে bracket গোনা: একটা counter দিয়ে [(]) আর [()]-এর পার্থক্য বোঝা যায় না।

Complexity

Time complexity: O(n) – প্রতিটা অক্ষর একবার push বা pop হয়। Space complexity: O(n) সবচেয়ে খারাপ ক্ষেত্রে (সবগুলোই opening bracket হলে)।
