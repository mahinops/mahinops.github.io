Heap / Priority Queue

এমন একটি structure যেখানে সবচেয়ে ছোট item সবসময় উপরে থাকে, আর add বা remove করা দ্রুত হয়।

মূল ধারণা (হাসপাতালের waiting room)

Emergency room-এ কে আগে এসেছে সেটা নয়, বরং যার অবস্থা সবচেয়ে জরুরি তাকে আগে দেখা হয়। Priority queue ঠিক এটাই করে। Min-heap এটি বানানোর একটি কার্যকর উপায়: এমন একটি tree যেখানে প্রতিটি parent তার children-এর চেয়ে ছোট বা সমান। তাই সবচেয়ে ছোট মানটা সবসময় একদম উপরে (root-এ) থাকে এবং সাথে সাথে পাওয়া যায়।

মজার ব্যাপার হলো, tree-টা কোনো pointer ছাড়াই একটা সাধারণ array-তে রাখা হয়। i index-এর item-এর জন্য: children থাকে 2i+1 আর 2i+2-তে, এবং parent থাকে (i-1)/2-তে। নিচের দুটি view আসলে একই data।

  • Push: নতুন item শেষে রাখুন, তারপর sift up করুন: parent-এর চেয়ে ছোট হলে parent-এর সাথে swap করুন।
  • Pop: root নিয়ে নিন, শেষ item-কে root-এ আনুন, তারপর sift down করুন: ছোট child-এর চেয়ে বড় হলে swap করুন।
  • Heapify: এলোমেলো array-কে heap বানান, শেষ parent থেকে root পর্যন্ত পেছনে এসে sift down করে।

Run করে দেখুন

অনুমোদিত: push N, pop, heapify N N N ... (heapify বর্তমান heap-কে ওই array দিয়ে বদলে দেয়)। সর্বোচ্চ 20টি operation এবং 15টি item।

নিজে চেষ্টা করুন

  • 9, 7, 5, 3, 1 push করুন (বড়টা আগে)। প্রতিটি নতুন item একদম উপরে পৌঁছে যায়। কেন?
  • 1, 2, 3, 4, 5 push করুন (ছোটটা আগে)। এবার কয়টি swap হয়?
  • heapify 9 8 7 6 5 4 3 2 1 run করুন এবং দেখুন tree নিচ থেকে উপরের দিকে কীভাবে ঠিক হয়।
  • বারবার pop করুন: মানগুলো sorted order-এ বের হয়। এটাই heap sort।

সাধারণ ভুল

  • array-টা sorted ভাবা। শুধু parent ≤ child নিয়মটা সত্য। Sibling আর cousin যেকোনো order-এ থাকতে পারে।
  • খালি heap-এ pop করা। h.a[0] "index out of range" বলে panic করে। আগে length দেখে নিন।
  • index-এর হিসাব ভুল। 0-based array-তে children থাকে 2i+1 আর 2i+2-তে (1-based বইয়ে 2i আর 2i+1)।
  • আসল Go code-এ সাধারণত container/heap ব্যবহার করা হয়, যা একই sift logic দিয়ে Push/Pop দেয়। এই page-এ দেখানো হয়েছে ভেতরে কী ঘটে।
Complexity, সহজ ভাষায়: সবচেয়ে ছোট মান পড়া সাথে সাথে হয় (O(1))। Push আর pop root থেকে leaf পর্যন্ত একটি path ধরে যায়, তাই প্রায় log₂(n) ধাপ লাগে (O(log n)): 1,000,000 item-এর জন্য মাত্র প্রায় 20টি swap। পুরো array-র heapify লাগে মাত্র O(n)।
