Two Pointers

দুটো nested loop-এর বদলে দুটো index pointer ব্যবহার করুন।

মূল ধারণা

ধরুন সংখ্যা লেখা কিছু পাথর sorted ক্রমে সাজানো আছে, আর দুজন মানুষ দুই প্রান্ত থেকে একে অপরের দিকে হাঁটছে। আপনার দরকার এমন দুটো পাথর যাদের যোগফল target-এর সমান। যোগফল খুব ছোট হলে বাঁ দিকের জন ডানে গিয়ে একটা বড় পাথরে দাঁড়ায়। খুব বড় হলে ডান দিকের জন বাঁয়ে গিয়ে একটা ছোট পাথরে দাঁড়ায়। প্রতিটা ধাপে একটা পাথর চিরতরে বাদ হয়ে যায়, তাই একবার পুরো list দেখলেই হয়।

একই কৌশলে list in place reverse করা যায়: দুই প্রান্তের মান swap করুন, দুটো pointer ভেতরের দিকে সরান, আর দেখা না হওয়া পর্যন্ত এটা repeat করুন।

Run করে দেখুন

নিজে চেষ্টা করুন

  • Pair mode, target 14: প্রতিবার কোন pointer সরছে আর কেন, লক্ষ করুন।
  • Target বদলে 100 করুন। Pointer দুটো কখন থামে, আর কী return হয়?
  • সংখ্যাগুলো এলোমেলো ক্রমে দিন। পেজ সেটা নেবে না। Unsorted data-তে two pointers কেন ভুল উত্তর দিত?
  • Reverse mode-এ গিয়ে odd সংখ্যক item (যেমন 5টা) দিন। মাঝের item-এর কী হয়?

সাধারণ ভুল

  • Unsorted input: “যোগফল ছোট, তাই বাঁ pointer এগোও” যুক্তিটা শুধু sorted list-এই খাটে।
  • Pair problem-এ l <= r ব্যবহার করা (l < r-এর বদলে): এতে একটা element নিজের সাথেই pair হয়ে যেতে পারে।
  • ভুল pointer সরানো: যোগফল ছোট হলে শুধু বাঁ pointer সাহায্য করতে পারে, কারণ সেটা সবচেয়ে ছোট candidate-এ আছে।

Complexity

Time complexity: O(n) – pointer শুধু ভেতরের দিকে যায়, তাই প্রতিটা item বড়জোর একবার দেখা হয়। Nested loop দিয়ে করলে লাগে O(n²)। Space complexity: O(1) – শুধু দুটো integer।
