Part 1: Go, concept ধরে ধরে

1. Variables and MemoryGo-র variable-কে memory-র একটা নামওয়ালা box হিসেবে দেখুন: declare, assign, copy, zero value আর shadowing। 2. Pointersবক্স আর তীর দিয়ে Go-র pointer বুঝুন: address-of, dereference, pass by value বনাম pointer, struct, nil আর panic। 3. Arrays vs SlicesSlice-কে একটা ছোট header (pointer, length, capacity) হিসেবে দেখুন, যা একটা backing array-র ওপর বসানো: append, growth, aliasing আর 3-index slice। 4. MapsGo-র map-কে একটা ফোন বইয়ের মতো দেখুন: set, overwrite, comma-ok lookup, delete, nil map panic আর random iteration order। 5. Functions and the Call StackStack frame কীভাবে push আর pop হয় দেখুন: function call, একাধিক return value আর recursion। 6. Closuresদেখুন একটা closure কীভাবে নিজের captured variable গুলো নিজের কাছে রাখে, আর Go 1.22-এ loop variable-এর পরিবর্তন কীভাবে একটা পুরনো bug ঠিক করেছে। 7. Defer, Panic and Recoverদেখুন defer stack কীভাবে last-in-first-out ক্রমে run হয়, panic কীভাবে stack unwind করে, আর recover কীভাবে সেটা ধরে ফেলে। 8. Strings, Bytes and Runesদেখুন Go-র string কীভাবে UTF-8 byte-এর একটা সারি, কেন len গোনে byte, আর rune ও range কীভাবে character ধরে ধরে যায়। 9. Structs and Methodsদেখুন value receiver একটা copy বদলায় আর pointer receiver আসলটা বদলায়, এবং range কেন struct element-এর copy নেয়। 10. InterfacesInterface value-কে (type, value) জোড়া হিসেবে দেখুন: method কীভাবে ঠিক code-এ পৌঁছায়, nil interface gotcha, আর type assertion। 11. Goroutines and Channelsদেখুন goroutine গুলো channel দিয়ে value পাঠানোর সময় unbuffered আর buffered channel-এ কে কখন block হয়, এবং close ও range কীভাবে কাজ করে। 12. Select and Timeoutsদেখুন select একসাথে কয়েকটা channel-এর জন্য অপেক্ষা করে যেটা আগে ready হয় সেটা run করে, এবং timeout ও default case কীভাবে কাজ করে। 13. Mutex and Data Raceদুটো goroutine কীভাবে counter++ করতে গিয়ে একটা update হারিয়ে ফেলে (data race) এবং Mutex কীভাবে সেটা ঠিক করে, তা ধাপে ধাপে দেখুন। 14. WaitGroup and Worker Poolদেখুন একটা worker pool কীভাবে নির্দিষ্ট সংখ্যক worker দিয়ে job-এর queue সামলায়, আর WaitGroup কীভাবে main-কে সব job শেষ হওয়া পর্যন্ত অপেক্ষা করায়। 15. Context and Cancellationদেখুন একটা context কীভাবে cancel signal আর deadline নিচের goroutine গুলোর কাছে পৌঁছে দেয়, এবং parent cancel করলে কী হয়।

Part 2: Data structures আর algorithms

1. Binary SearchSorted list-এ প্রতিবার অর্ধেক বাদ দিয়ে দ্রুত একটা মান খুঁজে বের করার পদ্ধতি। 2. Two Pointersদুটো pointer দিয়ে list-এর দুই প্রান্ত থেকে বা পাশাপাশি এগিয়ে nested loop ছাড়াই pair আর in place সমস্যার সমাধান। 3. Sliding Windowআগের position-এর কাজ আবার না করে window সরিয়ে সরিয়ে fixed আর growing সমস্যার সমাধান। 4. Hash Map: Two Sumএকটু বেশি memory খরচ করে hash map-এ আগে দেখা মান মনে রেখে Two Sum দ্রুত সমাধান করা। 5. Prefix Sumএকবার prefix sum বানিয়ে রাখলে যেকোনো range-এর যোগফল একটা subtraction-এই পাওয়া যায়। 6. Stack: Valid ParenthesesStack দিয়ে bracket-এর জোড়া ঠিক আছে কিনা check করা: সবশেষে খোলা bracket-টাই আগে বন্ধ হতে হয়। 7. Queue & Monotonic StackQueue FIFO ক্রমে item serve করে, আর monotonic stack দিয়ে next greater element এক pass-এ পাওয়া যায়। 8. Linked ListLinked list reverse করা আর fast ও slow pointer দিয়ে cycle detect করা, ছবিতে ধাপে ধাপে। 9. SortingBubble, insertion, merge আর quick sort: চারটা classic sorting algorithm পাশাপাশি দেখুন। 10. Recursion Call TreeRecursion-এর call tree আর memoization কীভাবে একই sub-problem বারবার হিসাব করা থামায়, fib দিয়ে দেখুন। 11. Backtrackingএকটা choice নিয়ে এগিয়ে, না মিললে undo করে পরেরটা try করা: subsets আর N-Queens দিয়ে backtracking দেখুন। 12. Tree TraversalsBinary tree-র সব node কীভাবে preorder, inorder, postorder (live call stack-সহ) এবং level-order (queue-সহ) ক্রমে ঘুরে দেখা হয়, তা run করে দেখুন। 13. Binary Search Tree: Insert and SearchBST-তে সংখ্যা insert ও search করার সময় প্রতিটি ধাপে left বা right বেছে নেওয়ার পথটি run করে দেখুন। 14. Trie (Prefix Tree)Trie-তে word insert করা এবং search বা prefix query করার সময় অক্ষর ধরে ধরে নামার পথটি run করে দেখুন। 15. Heap / Priority QueueHeap-এ push, pop ও heapify করার সময় sift up আর sift down কীভাবে কাজ করে, তা array ও tree দুই রূপেই দেখুন। 16. Graph: BFS and DFSBFS আর DFS কীভাবে queue ও stack ব্যবহার করে একটি graph-এর সব node ঘুরে দেখে, তা step by step দেখুন। 17. Topological SortKahn's algorithm কীভাবে indegree আর queue ব্যবহার করে task গুলোকে dependency মেনে সাজায়, তা step by step দেখুন। 18. Dijkstra's Shortest PathDijkstra কীভাবে priority queue ব্যবহার করে রাস্তার দৈর্ঘ্য মেনে সবচেয়ে কম খরচের path খুঁজে পায়, তা step by step দেখুন। 19. Union-Find (Disjoint Sets)Union-Find-এ union আর find কীভাবে root ধরে কাজ করে এবং path compression কীভাবে tree ছোট রাখে, তা step by step দেখুন। 20. Dynamic Programming TableDynamic programming-এ ছোট সমস্যার উত্তর table-এর cell-এ লিখে কীভাবে বড় সমস্যার উত্তর বের করা হয়, তা stairs, LCS ও knapsack-এ step by step দেখুন। 21. Merge IntervalsOverlap করা interval গুলো sort করে একবার sweep-এ কীভাবে merge করা হয়, তা step by step দেখুন। 22. Bit ManipulationBinary switch-এর সারি হিসেবে সংখ্যা দেখে AND, OR, XOR, shift ও bit গোনার trick কীভাবে কাজ করে, তা step by step দেখুন।
