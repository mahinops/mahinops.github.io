Strings, Bytes and Runes

Go-র string হলো শুধু-পড়া byte-এর একটা সারি। চোখে দেখা একটা character কখনো 1 থেকে 4 টা byte নিতে পারে।

মূল ধারণা

String-কে ভাবুন নম্বর দেওয়া ঘর-ওয়ালা একটা ফিতা। সাধারণ ইংরেজি অক্ষর একটা করে ঘর নেয়। “é”-র মতো অক্ষরের লাগে দুটো ঘর, আর একটা emoji-র লাগে চারটা, কারণ Go text জমা রাখে UTF-8 হিসেবে।

তাই len(s) গোনে ঘর (byte), character নয়। Rune হলো Go-র ভাষায় একটা character (একটা Unicode code point)। []rune(s) আর for i, r := range s string-টাকে byte ধরে ধরে না গিয়ে character ধরে ধরে হাঁটে।

Run করে দেখুন

নিজে চেষ্টা করুন

  • প্রথমে default héllo🙂 দিন, তারপর hello, তারপর ééé। byte-এর সংখ্যা আর rune-এর সংখ্যা মিলিয়ে দেখুন।
  • index 1 করুন, তারপর 2। s[1] কেন é character-টা নয়?
  • range loop-এ লক্ষ করুন: multi-byte character-এর জায়গায় index i 2 বা 4 করে লাফায়।

সাধারণ ভুল

  • len(s)-কে character-এর সংখ্যা ধরা। এর বদলে utf8.RuneCountInString(s) বা len([]rune(s)) ব্যবহার করুন।
  • s[i] লিখে character আশা করা। আসলে একটা byte পাওয়া যায় (একটা byte, অর্থাৎ uint8)।
  • Multi-byte character-এর মাঝখানে slice করলে ভাঙা text তৈরি হয়।
  • String সরাসরি বদলাতে চাওয়া (s[0] = 'H' লিখলে compile error হয়)। String বদলানো যায় না (immutable); নতুন একটা বানাতে হয়।
