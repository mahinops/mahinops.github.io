Variables and Memory

Variable হলো memory-র একটা নামওয়ালা box, যেটা এক type-এর একটা value ধরে রাখে।

মূল ধারণা

এক সারি locker-এর কথা ভাবুন। প্রতিটা locker-এর দরজায় একটা নাম লেখা (variable-এর নাম), ভেতরে থাকে একটা জিনিস (value), আর একটা locker নম্বর আছে (memory address)। age := 30 লেখার মানে হলো “একটা খালি locker নাও, তার গায়ে age লিখে দাও, ভেতরে 30 রাখো”।

other := age লিখলে Go ভেতরের জিনিসটার একটা ফটোকপি করে নতুন একটা locker-এ রাখে। copy বদলালে আসলটা কখনো বদলায় না। Go-র প্রায় সবকিছুই এভাবে কাজ করে: assignment করলে value copy হয়।

Run করে দেখুন

নিজে চেষ্টা করুন

  • “Declare, copy আর change” উদাহরণে other-এ অন্য একটা সংখ্যা দিন: age কি কখনো বদলায়?
  • “Zero values” উদাহরণে দেখুন, আপনি কিছু set না করলেও প্রতিটা variable-এর একটা value আছে। একটা string শুরুতে কী থাকে?
  • “Shadowing” উদাহরণে ভেতরের মান বদলান আর দেখুন বাইরের x একই থাকছে।

সাধারণ ভুল

  • ভাবা যে b := a লিখলে b, a-এর আরেকটা নাম হয়ে যায়। আসলে এটা একটা স্বাধীন copy তৈরি করে।
  • Go-তে ব্যবহার না করা variable হলে compile error হয়: declared and not used: x।
  • কোনো block-এর ভেতরে = লেখার জায়গায় := লিখলে বাইরের variable update হয় না, বরং একটা নতুন variable তৈরি হয় (shadowing)।
