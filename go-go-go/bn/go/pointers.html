Pointers

Pointer হলো এমন একটা box, যার ভেতরে অন্য একটা box-এর address থাকে। এটাকে একটা তীর (arrow) হিসেবে আঁকা যায়।

মূল ধারণা

মনে করুন আপনার বন্ধুর একটা বাড়ি আছে। Value হলো বাড়িটা নিজেই। Pointer হলো একটা কাগজের টুকরো, যাতে বাড়ির ঠিকানা লেখা। কাউকে যদি বাড়ির ফটোকপি দেন (pass by value), সে তাতে রং করলেও আপনার আসল বাড়ি আগের মতোই থাকবে। আর যদি ঠিকানার কাগজটা (pointer) দেন, সে সেখানে গিয়ে আপনার আসল বাড়িতেই রং করে দিতে পারবে।

দুটো symbol দিয়েই পুরো কাজ হয়: &x মানে “x-এর address” (তীর বানানো), আর *p মানে “p যেখানে point করছে সেখানে যাও” (তীর ধরে গিয়ে পড়া বা লেখা)।

Run করে দেখুন

নিজে চেষ্টা করুন

  • “Address-of আর dereference” উদাহরণে *p দিয়ে যে নতুন মান লেখা হচ্ছে সেটা বদলান। দেখবেন x-এর নাম একবারও না লিখেও তার মান বদলে যাচ্ছে।
  • “Pass by value বনাম pointer” উদাহরণে ধীরে ধীরে ধাপ দেখুন: কোন function caller-এর x বদলায়, আর কেন?
  • “new() আর nil pointer panic” উদাহরণে খুঁজে বের করুন প্রোগ্রাম ঠিক কোন ধাপে crash করে।
  • “দুটো pointer, একটাই target” উদাহরণে এক pointer দিয়ে লিখুন, আরেকটা দিয়ে পড়ুন।

সাধারণ ভুল

  • nil pointer dereference করলে panic হয়: invalid memory address or nil pointer dereference। আগে p != nil check করে নিন।
  • Value pass করার পরেও আশা করা যে function আপনার variable বদলে দেবে। এর বদলে &x pass করুন আর function-এ *int parameter নিন।
  • p (address) আর *p (যে value-তে point করছে) গুলিয়ে ফেলা। p print করলে address দেখা যায়, আপনার data নয়।
  • Local variable-এর pointer return করা Go-তে ঠিক আছে (variable-টা heap-এ সরে যায়), C-র মতো সমস্যা হয় না।
