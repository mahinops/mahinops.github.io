Structs and Methods

Struct কয়েকটা field-কে একটা box-এ জড়ো করে। Method হলো সেই box-এর সাথে জোড়া একটা function।

মূল ধারণা

Struct হলো নাম-লেখা ফাঁকা ঘরওয়ালা একটা ফর্ম (Name, Age, ...)। Method হলো পূরণ করা ফর্মের ওপর করা যায় এমন একটা কাজ, যেমন form.Submit()।

প্রতিটা method নিয়ে আসল প্রশ্ন হলো: সে কি আসল ফর্মটা পায়, নাকি একটা ফটোকপি? Value receiver (c Counter) পায় একটা ফটোকপি, তাই পরিবর্তন হারিয়ে যায়। Pointer receiver (c *Counter) পায় আসল ফর্মের address, তাই পরিবর্তন থেকে যায়।

Run করে দেখুন

নিজে চেষ্টা করুন

  • “Value vs pointer receiver” উদাহরণে দেখুন দুটো method call-এর মধ্যে কোনটা main-এর c বদলায়।
  • “range copies struct elements” উদাহরণে প্রথম loop (কিছু বদলায় না) আর দ্বিতীয় loop (element বদলায়) মিলিয়ে দেখুন।

সাধারণ ভুল

  • যে method-এর struct বদলানোর কথা, সে যদি value receiver ব্যবহার করে, তাহলে সে চুপচাপ একটা copy বদলায়।
  • for _, c := range items { c.n++ } লিখলে loop-এর copy বদলায়, slice-এর element নয়। items[i] ব্যবহার করুন বা pointer-এর slice নিন।
  • একই type-এ value আর pointer receiver মেশানো যায়, কিন্তু এতে বিভ্রান্তি হয়; কোনো method value বদলাতে চাইলে, বা struct বড় হলে, pointer receiver বেছে নিন।
  • sync.Mutex আছে এমন struct copy করলে lock-টাও copy হয়ে যায়। pointer pass করুন।
