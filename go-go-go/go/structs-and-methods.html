Structs and Methods

A struct groups fields into one box. A method is a function attached to that box.

The idea

A struct is a form with labelled blanks (Name, Age, ...). A method is an action you can perform on a filled-in form, like form.Submit().

The key question for every method is: does it get the form, or a photocopy? A value receiver (c Counter) gets a photocopy, so changes vanish. A pointer receiver (c *Counter) gets the address of the real form, so changes stick.

Common mistakes

  • A method that should modify the struct but uses a value receiver: it silently changes a copy.
  • for _, c := range items { c.n++ } modifies the loop copy, not the slice element. Use items[i] or a slice of pointers.
  • Mixing value and pointer receivers on one type is allowed but confusing; pick pointer receivers if any method must modify the value or the struct is large.
  • Copying a struct that contains a sync.Mutex copies the lock too. Pass a pointer.
