Variables and Memory

A variable is a named box in memory that holds a value of one type.

The idea

Think of a row of lockers. Each locker has a name on the door (the variable name), something inside (the value) and a locker number (its memory address). age := 30 says “grab a free locker, label it age, put 30 inside”.

When you write other := age, Go photocopies what is inside into a new locker. Changing the copy never changes the original. Almost everything in Go works this way: assignment copies the value.

Watch it work

Try it

  • In “Declare, copy, change” set other to a different number: does age ever change?
  • In “Zero values” notice every variable has a value even though you never set it. What does a string start as?
  • In “Shadowing” change the inner value and check that the outer x stays the same.

Common mistakes

  • Thinking b := a makes b an alias of a. It makes an independent copy.
  • Unused variables are a compile error in Go: declared and not used: x.
  • Using := when you meant = inside a block creates a new variable (shadowing) instead of updating the outer one.
