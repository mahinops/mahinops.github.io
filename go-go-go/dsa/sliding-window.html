Sliding Window

Reuse the work from the last position instead of starting over.

The idea

Picture looking through a frame that shows 3 houses at a time while you walk down a street. To know the total value of the houses in view after one step, you do not re-add all 3: you add the new house that appeared and subtract the one that left.

A window can also grow and shrink: for “longest stretch with no repeated letter”, the right edge grows one letter at a time, and when a repeat appears the left edge jumps forward just far enough to remove it.

Watch it work

Try it

  • Fixed window: use k = 1, then k = the full length. What does each case do?
  • Notice how the sum changes by one add and one subtract per slide, never a full re-add.
  • Longest substring: try pwwkew. Watch the left edge jump when a repeat shows up.
  • Try a text with all different letters, then one with all the same letter.

Common mistakes

  • Re-adding the whole window each time turns O(n) into O(n·k).
  • Off-by-one on the dropped item: when the window ends at i, the item that just left is nums[i-k].
  • Forgetting stale entries: in the substring version a letter seen before the window start must be ignored (idx >= left).

How fast is it?

Time: O(n) – every item enters the window once and leaves at most once. Space: O(1) for the fixed window; O(alphabet) for the substring version (the map of last-seen positions).
